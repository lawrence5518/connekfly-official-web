# Solución simple — Web Oficial ConnekFly

Este ZIP ya trae corregida la Web Oficial.

Qué corrige:
- La ruta de invitación `/i/CODIGO` ya existe.
- El botón de descarga usa siempre el APK del último Release de GitHub.
- El enlace de invitación ya no debe caer en 404.

Qué haces tú:
1. Abre GitHub.
2. Entra al repo `connekfly-official-web`.
3. Sube/reemplaza estos archivos del proyecto con los de este ZIP.
4. GitHub guarda los cambios.
5. Vercel se actualiza solo.

No tienes que tocar Vercel.
No tienes que tocar Android.
